# Style

- `EssaiStyle.unity` : essai du style visuel (formes simples, ToonLit, ciel en dégradé, brouillard, post-traitement léger), générée par `Outils > Rendu > Créer la scène d'essai de style`. À valider avec Emeline.
- `*.mat`, `PostTraitement.asset` : ses matériaux et son post-traitement, générés avec la scène.
