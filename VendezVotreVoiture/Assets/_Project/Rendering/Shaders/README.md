# Shaders

- `ToonLit.shader` (`Projet/ToonLit`) : couleur pleine, passage doux vers une couleur d'ombre teintée, ombres portées de la lumière principale, liseré de contre-jour, brouillard. Une passe éclairée, compatible SRP Batcher et instancing.
- `GradientSky.shader` (`Projet/GradientSky`) : ciel en dégradé haut, horizon, bas, sans texture.
