# Rendering

- `MobileRendering.cs` : réglages techniques du rendu mobile (`Mobile_RPAsset`, `Mobile_Renderer`) : MSAA x4, échelle 0,85, sans HDR, ombres douces à 30 m, forward, sans lumières additionnelles. Menu `Outils > Rendu > Appliquer les réglages mobiles`.
- `StyleTestScene.cs` : crée la scène d'essai de style `Scenes/Essais/EssaiStyle.unity`.
- `StyleAssets.cs` : ses matériaux, son ciel et son post-traitement, dans `Rendering/Essai/`.
