# Tooling

Outils éditeur du projet (assembly `Project.Editor`, absente des builds).

- `Setup/` : réglages mobiles du projet.
- `Rendering/` : réglages du rendu mobile et essai de style.
- `WebServe/` : build Web servie sur le réseau local.
- `Layout/` : disposition de dev partagée.
- `Network/` : adresse locale, partagée avec `PhoneRemote`.
