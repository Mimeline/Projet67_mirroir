# Manager

- `SceneManager.cs` : charge et décharge les scènes en additif.
- `SceneNames.cs` : chemins des scènes.
- `GameManager.cs` : gère les niveaux, lance les différentes logiques en fonction du contexte.
- `Boot.cs` : objet indestructible de la scène `Root`, porte les gestionnaires et charge le lobby au démarrage.
