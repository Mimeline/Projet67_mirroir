# Portrait

Gabarit de la build Web : le jeu reste en vertical. La zone de jeu prend toute la hauteur, et sa largeur ne dépasse pas celle d'un iPad à la verticale (3:4) ; au-delà, des bandes noires.

- `index.html` : charge la build Unity dans le canevas.
- `style.css` : cadre vertical centré.

Choisi dans `ProjectSettings` (`webGLTemplate: PROJECT:Portrait`).
