# Tools

Outils de l'éditeur, indépendants du jeu (absents des builds). Assembly `Tools.Editor`, sauf `PhoneRemote` (la sienne).

- `PhoneRemote/` : téléphone distant au Play.
- `Devices/` : appareils du simulateur (iPhone 15 Pro avec Dynamic Island).
- `Setup/` : réglages mobiles du projet.
- `Rendering/` : réglages du rendu mobile, générateur de l'essai de style.
- `WebServe/` : build Web servie sur le réseau local.
- `Layout/` : disposition de dev, appliquée à l'ouverture.
- `Network/` : adresse locale, partagée avec `PhoneRemote`.
- `Memory/` : nettoyage régulier de la mémoire de l'éditeur.
