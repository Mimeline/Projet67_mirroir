# Scenes

- `SceneSkeleton.cs` : crée les scènes manquantes du squelette et les inscrit dans le build. Menu `Outils > Scènes > Créer le squelette`.
- `SceneFactories.cs` : fabrique `Root`, le décor 3D du lobby et son interface.
- `PlayFromAnyScene.cs` : Play depuis n'importe quelle scène ajoute `Root` par-dessus.
