# Devices

Appareils ajoutés au simulateur de Unity (vue Game en mode Simulator).

- `iPhone15Pro.device` : iPhone 15 Pro en portrait, 1179 × 2556 à 460 dpi, zone sûre (59 pt en haut, 34 pt en bas) et encoche de la Dynamic Island.
- `iPhone15Pro_Overlay.png` : contour du téléphone (bord, coins arrondis, Dynamic Island) posé sur l'écran, généré par script.

Les valeurs de zone sûre sont celles d'iOS pour cet appareil ; Unity documente un écart possible sur les appareils à Dynamic Island en portrait : vérifier sur un vrai iPhone.
